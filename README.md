# agregate-bot

## Импорт товаров (админ-бот магазина)

1. В админ-боте: **Товары → категория → “Массовое добавление”**.
2. Отправьте CSV-файл документом. Формат строки:
   `Название; Цена; Описание (опционально)`.
3. Проверьте предпросмотр и нажмите **«Импортировать»**.

Пример файла: [`samples/products_import_sample.csv`](samples/products_import_sample.csv).
